# QA Internship

## Цель проекта

Получить практический опыт тестирования реального цифрового продукта в составе проектной команды и применить навыки ручного тестирования на веб- и мобильных платформах.

## О продукте

Стажировка проходила в команде Gidio, развивающей AI-гида для самостоятельных городских прогулок. Продукт представлен сайтом, личным кабинетом, чат-ботами и mini app.

## Что реализовано лично

- проведено ручное тестирование сайта, личного кабинета, Telegram- и MAX-ботов, а также mini app;
- проверены основные пользовательские сценарии и переходы между платформами;
- выполнены smoke-, регрессионное, исследовательское, интеграционное и кроссплатформенное тестирование;
- проверены адаптивность интерфейса и совместимость с разными браузерами;
- подготовлены тест-кейсы и чек-листы;
- найдены, воспроизведены и задокументированы дефекты;
- оформлены баг-репорты с окружением, шагами воспроизведения, ожидаемым и фактическим результатом;
- выполнены ретест исправлений и сопровождение задач до завершения;
- проведены проверки API и анализ сетевых запросов;
- организовано взаимодействие с разработчиком, дизайнером и другими участниками команды.

## Использованные инструменты

Postman, Chrome DevTools, Safari, Chrome, Firefox, Edge, Яндекс Браузер, Telegram, MAX, macOS, Android, dev-стенд и инструменты адаптивного тестирования.

## Полученный результат

Получен опыт полного цикла ручного тестирования реального продукта: от анализа функциональности и подготовки тестовой документации до регистрации дефектов, проверки исправлений и регрессионного тестирования релизов. Освоена работа с распределением задач, приоритизацией дефектов и регулярным обсуждением результатов в проектной команде.
